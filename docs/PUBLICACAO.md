# Escopo da publicação

Incluído: código, marca, fontes/licenças, bibliotecas fixadas, esquema SQL, testes fictícios, histórico técnico resumido e gestão/operação.

Excluído: configuração ativa, .env, capturas preview-*, dependências instaladas, caches, exportações DOCX/PDF geradas, metadados locais, ZIPs antigos, backups, dados do navegador e registros reais. Arquivos locais excluídos foram preservados.

README e AUTH-SETUP anteriores foram preservados fora da pasta versionada, pois reuniam relatos operacionais particulares. O histórico técnico está resumido no CHANGELOG.

GitHub não recebe dump do banco ou de usuários Auth. Esta organização não muda plano, cobrança, permissões do banco ou implantação. Conferir visibilidade do destino antes de enviar; não tornar público automaticamente.

Antes do commit, preparar arquivos no índice e executar node tools/check-repository.cjs --staged. A verificação informa caminhos/tipos de achado, sem imprimir credenciais; revisão manual continua necessária.
